# Privacy Blur Tabs

Mod Zen Browser yang nge-blur **nama tab** dan **ikon tab**. Arahkan kursor ke tab untuk membukanya.

Pengaturan (Settings -> Sine Mods): kekuatan blur, opsi tab aktif tidak ikut di-blur, dan saklar matikan sementara.

Pasangan dari ekstensi *Privacy Blur*, yang meng-handle isi halaman web.
